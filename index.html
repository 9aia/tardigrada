tardigrada ​

Dormant identity that persists anywhere.

tardigrada is the per-machine, per-human age identity behind encrypted stores — cuora vaults, tamias sealed packs, rage files. One keyfile, one set of verbs: bootstrap it, read its recipient, move it between tools and machines.
