Command-Line Help for tardigrada ​

This document contains the help content for the tardigrada command-line program.

tardigrada — the per-machine, per-human age identity behind encrypted stores. init bootstraps the identity (generate + store, never clobbers); show prints the age1… recipient to share with tools that seal to it; import/export move key material between files and machines; backend inspects storage. --json is honored on every verb; the identity key is the only secret tardigrade touches.

tardigrada ​

tardigrada — the per-machine, per-human age identity behind encrypted stores. init bootstraps the identity (generate + store, never clobbers); show prints the age1… recipient to share with tools that seal to it; import/export move key material between files and machines; backend inspects storage. --json is honored on every verb; the identity key is the only secret tardigrade touches.

Usage: tardigrada [OPTIONS] <COMMAND>

Commands: ​
  • init — Bootstrap the age identity — generate + store it in the configured backend. Never clobbers an existing identity: a second init reports the current recipient and exits clean. Under keyring/auto an existing keyfile identity is adopted into the store (migration), never orphaned
  • show — Print the age1… recipient of the stored identity — the value tools seal to (cuora vaults, tamias packs, rage recipients files). Goes to stdout bare (scriptable); backend/source context on stderr. Fails when no identity exists — run tardigrada init first
  • import — Adopt an existing identity.txt-style keyfile as this machine's identity — parses the file, stores the identity in the configured backend (overwrites whatever is there; the old key is gone for good)
  • export — Write the identity keyfile out — mode 0600, the same format import reads. --out PATH writes a file for moving between tools/machines; bare export prints the AGE-SECRET-KEY-… line to stdout (pipe it into another tool's keyfile, or rage -e -i /dev/stdin). This is the explicit escape hatch — the value is secret
  • backend — Inspect the configured identity backend — the resolved source (keyring or file), the configured mode (keyring/auto/file), and whether an explicit file pin is in effect
  • manifest — Capabilities, JSON shapes, env vars — agent self-discovery (always JSON)
Options: ​
  • --json — Emit JSON — stable machine shapes on every verb; errors are {"error": "…"} on stderr with a non-zero exit
  • --identity-file <PATH> — Identity keyfile path, overriding $TARDIGRADA_IDENTITY_FILE and the XDG default ($XDG_CONFIG_HOME/tardigrada/identity.txt). An explicit pin always selects the file backend — the keyring is never probed
  • -h, --help — Print help (see a summary with '-h')
  • -V, --version — Print version
